# A01_5512

## A01 - GitHub Basics OPIM5512

### California Housing Boxplot:
This project loads the California Housing dataset and creates a boxplot of the Median Income (MedInc) column that is saved into the figs/ folder.

### Files
- `src/boxplot.py`: Python script that generates the boxplot
- `figs/boxplot.png`: Saved boxplot image

### Requirements
Run this code in your terminal to install the required Python packages:
`pip install scikit-learn matplotlib pandas`

## How to Use This Project

### 1. Clone the Repository
Using GitHub Desktop:
1. Open GitHub Desktop
2. Select File: Clone Repository
3. Choose this repository (A01_5512)
4. Select a local folder
5. Click Clone

Or using Git:
`git clone <repository-url>`

### 2. Open the Project
Open the project folder in VS Code or your preferred Python IDE.

### 3. Install Dependencies
Open a terminal in the project folder and run: 
`pip install scikit-learn matplotlib pandas`

### 4. Run the Script
From the project folder, run:
`python src/boxplot.py`

### 5. View the Output
The script will:
1. Load the California Housing dataset
2. Create a boxplot of Median Income
3. Save the figure to figs/boxplot.png
